# Landing Page Animada de Patins

Landing page desenvolvida como projeto do curso **Full Stack da Rocketseat**, no módulo de **CSS com animações**.

## Demonstração

Acesse o projeto publicado no GitHub Pages:

[Landing Page Animada de Patins](https://eduardonobilioni.github.io/Landing-page-animada-patins/)

## Sobre o projeto

O projeto apresenta a landing page da Snitap, uma marca fictícia de patins. A interface foi construída com foco em:

- Layout responsivo;
- Animações e transições com CSS;
- Interações de hover no menu e nos links sociais;
- Animação de elementos da seção principal;
- Galeria de imagens;
- Uso de fontes do Google Fonts.

## Tecnologias

- HTML5
- CSS3
- CSS Animations e Transitions
- Google Fonts
- GitHub Pages

## Como executar localmente

1. Clone este repositório:

   ```bash
   git clone https://github.com/EduardoNobilioni/Landing-page-animada-patins.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd Landing-page-animada-patins
   ```

3. Abra o arquivo `index.html` no navegador.
